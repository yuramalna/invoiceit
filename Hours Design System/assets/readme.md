# assets

Empty on purpose.

No logo, icon set, fonts or imagery were supplied with the brief, and none were
invented. Where a mark is needed, render the word **Hours** in Archivo 600 at −.05em
with a terracotta period (see `guidelines/brand-wordmark.card.html`).

Drop real assets here when they exist:

- `assets/logo.svg` — then update `thumbnail.html` and `SidebarNav`'s wordmark.
- `assets/fonts/*.woff2` — then replace the Google Fonts `@import` in
  `tokens/fonts.css` with `@font-face` rules pointing at these files.
- `assets/icons/` — only if a real icon set replaces the Lucide substitution.
