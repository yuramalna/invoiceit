One-line: use for any committed action; `primary` at most once per screen, `accent` only for "Start timer".

```jsx
<Button variant="primary" icon="Plus">New entry</Button>
<Button variant="ghost" size="sm">Cancel</Button>
```

Variants: primary (pine 700), secondary (white + rule, the workhorse), ghost (toolbars, row actions), accent (running-clock actions only), danger (outline rust, destructive).
